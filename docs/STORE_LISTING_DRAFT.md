**An agent instruction file plus practical documentation templates for maintaining a vibe-coded project.**

Studio Engineering Kit gives you a short, reusable engineering prompt and an optional repository starter to help organize the work around an AI-built app: what the product is, which engineering boundaries matter, what has actually been tested, and what still needs attention.
