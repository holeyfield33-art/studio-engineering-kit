# Studio Engineering Kit

**A small, practical engineering instruction pack for AI coding agents — with optional maintained-repository templates.**

**What it does not do:** This is advisory prompt and documentation content. It **cannot force an agent to follow instructions, run tests, enforce authorization, certify an app, or guarantee better-engineered code.** Results depend on the model, project, user direction and actual verification.

## How to use the free core

1. Follow the [setup guide](docs/PLATFORM_SETUP.md) for your actual tool.
2. Inspect the project's existing `AGENTS.md`, `CLAUDE.md` and other rules. Do **not** overwrite them blindly.
3. Give the agent one bounded task; inspect its real code diff and executed tests.
4. Treat a request to “summarize the kit instructions” as a **loading check only**. It does not prove correct engineering behavior.
